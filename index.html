Personal Health Insights is a private, single-user project for reviewing the owner's Oura sleep, activity, and recovery data with optional AI-assisted analysis.

个人健康趋势分析工具：通过 Oura 官方 API 读取本人授权的数据，结合本机整理和可选的 AI 辅助分析，了解睡眠、活动与恢复的长期变化。

This website contains project information only. It has no Oura sign-in, health-data upload, or public dashboard. The data integration is being set up separately.
01 / CONNECT

Owner-authorized access

The planned local integration uses Oura OAuth authorization and requests only the data needed for the owner's analysis.

02 / REVIEW

Understand trends

Review sleep timing, activity, heart rate, HRV, and other available recovery metrics over time.

03 / REFLECT

Explore associations

Compare personal habits and recorded tags with trends. Associations do not establish causes or medical diagnoses.

Built for one person's use

This project is operated by fropic for the account owner's personal use. It is not open for public registration and is not an official Oura product or an Oura-endorsed service.

Read the privacy notice for the intended data flow and the terms of use for the project's scope.
